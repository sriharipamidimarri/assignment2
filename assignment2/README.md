
# Assignment 2: CDP Chatbot
This project implements a chatbot that answers "how-to" questions for Segment, mParticle, Lytics, and Zeotap using Python Flask for the backend and React for the frontend.

## Instructions
1. **Backend**: Run `app.py` using `python app.py`.
2. **Frontend**: Create a React app and replace `src/App.js` with provided content.
3. **Dependencies**: Install Flask and React dependencies.

## Improvements and Suggestions
- Extend functionality with NLP frameworks.
- Handle cross-CDP comparisons for advanced questions.
